RADTECH SIMULATION WEBSITE V3

ปรับตามข้อมูลที่ผู้ใช้ส่งมาแล้ว

1. โลโก้จริงที่อัปโหลดอยู่ด้านขวาบนของ Header
2. ชื่อ RADTECH SIMULATION อยู่ตรงกลาง Header
3. สไลด์คณะผู้จัดทำอัตโนมัติ 4 คน:
   - นางสาวณัฐณิชาย์ แสงเพชรรัตน์
   - นางสาวพรลภัส สายเสมา
   - นางสาวศรีอัปสร รัตฉวี
   - ผู้ช่วยศาสตราจารย์ ดร.ฐิติพงศ์ แก้วเหล็ก (อาจารย์ที่ปรึกษา)
4. ใช้รูปบุคคลจาก PDF ที่ผู้ใช้ส่งมา โดยตัดเป็นรูปสำหรับ slideshow
5. ฝัง Heyzine E-book จาก:
   https://heyzine.com/flip-book/8b593a2b50.html
6. มีส่วน PLAY GAME สำหรับเชื่อม Unity WebGL
7. มี Footer สำหรับช่องทางติดต่อ

การเชื่อม Unity:
- Build Unity เป็น WebGL
- ใส่โฟลเดอร์ไว้เป็น unity/
- แก้ startGame() ใน script.js เป็น:
  window.location.href="unity/index.html";

ช่องทางติดต่อ:
แก้ href ของ Email/Facebook/Instagram/Website ใน index.html
